# SCANPRO

Aplicativo web local-first para leitura de gabaritos existentes, com foco em uso no iPhone e hospedagem no GitHub Pages.

## Destaques atuais

- modelos PROEA 6º ao 9º prontos para carga local;
- captura iPhone-first com camera ou foto da galeria;
- leitura OMR assistida por modelo calibrado;
- deteccao automatica do codigo do caderno (`P0602`, `M0702`, `N0902`, etc.) para escolher o modelo correto quando encontrado;
- resultados por aluno com percentual e exportacao CSV/backup JSON.
